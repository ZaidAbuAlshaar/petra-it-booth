شاشة جناح كلية تكنولوجيا المعلومات – جامعة البترا  (النسخة المحدّثة)
=====================================================================

طريقة التشغيل (أسهل طريقة)
--------------------------
• دبل كليك على  START_BOOTH.bat
  ← بيفتح العرض بملء الشاشة على Chrome (أو Edge إذا Chrome مش موجود)
  ← الصوت والموسيقى بيشتغلوا لحالهم بدون ما حدا يضغط
  ← للخروج: F11 أو Alt+F4

• START_BOOTH_KIOSK.bat  = نفس الشي بس "مقفول" (الزوار ما بيقدروا يطلعوا منه)
  ← للخروج: Alt+F4 فقط

• على Mac: دبل كليك على START_BOOTH_MAC.command (إذا macOS منعه: System Settings ← Privacy & Security ← Open Anyway).

• مهم: فكّوا ضغط الـ zip أولاً (Extract All)، التشغيل من داخل الـ zip ما بيشتغل.

• نسخة أونلاين: https://zaidabualshaar.github.io/petra-it-booth/

• ممكن كمان تفتحوا index.html عادي بأي متصفح. وقتها المتصفح ممكن يمنع الصوت
  لحد أول ضغطة، فبيطلع زر "اضغطوا لتفعيل الصوت والموسيقى".

الموسيقى الخلفية
----------------
• الموسيقى تشتغل طول الوقت بصوت منخفض.
• لما يبلش فيديو فيه صوت (كلام/موسيقى خاصة فيه) الموسيقى بتخفت وبتوقف تلقائياً،
  ولما يخلص الفيديو أو حدا يوقفه بترجع لحالها.
• زر 🎵 الموسيقى = تشغيل/إيقاف الموسيقى فقط.   زر 🔊 الصوت = كتم كل شي.
• الملفات في مجلد music (مقطوعتين أصليتين مولّدتين بـ Lyria، بدون حقوق لطرف ثالث).
  لتغييرها: حطوا ملف mp3 جديد بمجلد music وعدّلوا MUSIC_TRACKS في أول script.js.
• مستوى الموسيقى: MUSIC_VOLUME في أول script.js (حالياً 0.35).

الفيديوهات
----------
كل فيديو في script.js إله سطر:
{ title: "الاسم", file: "videos/video01.mp4", category: "clubs", sound: false }
• sound: true  = الفيديو فيه صوت مسموع ← الموسيقى بتتوقف وقته.
  (تم فحص كل الفيديوهات: 04، 05، 06، 08، 12 فيها مسار صوت بس صامت تماماً،
   فاعتبرناها بدون صوت والموسيقى بتضل شغالة معها)
• إذا أضفتوا فيديو جديد ونسيتوا sound، العرض بيكتشف لحاله إذا فيه مسار صوت.
  بس الأفضل تكتبوها: لو الفيديو فيه مسار صوت صامت، الكشف التلقائي بيعتبره بصوت.
• vol: مستوى صوت الفيديو من 0 لـ 1 (لتقريب الفيديوهات العالية من المنخفضة).
• الأقسام: clubs / majors / achievements / research / projects / abet

ميزات إضافية
------------
• يشتغل بدون إنترنت (الخط محفوظ داخل المشروع). فقط قسم Live Cyber Threat Map
  وتزامن الساعة بدهم إنترنت.
• الشاشة ما بتطفي لحالها وقت العرض (Wake Lock).
• إذا حدا وقف الفيديو أو فتح الخريطة وراح، بعد دقيقتين بدون لمس العرض برجع يشتغل لحاله.

------------------
